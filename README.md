# TIA QuickView Demo

![TIA QuickView logo](./tiaQuickViewLogo.webp)

Open the demo: https://jfk-solutions.github.io/TiaQuickViewDeploy/

## Demo Restrictions

- Demo mode allows opening only 3 PLC blocks per page load.
- Reloading the page resets the demo counter.
- Project files are parsed locally in the browser and are not uploaded to a server by this static deployment.
